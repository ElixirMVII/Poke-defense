# Pokémon Tower Defense

เกม tower defense ที่เล่นบนเบราว์เซอร์ล้วน ๆ ไม่ต้องติดตั้งหรือ build อะไรเลย
จุดขายคือ **ระบบธาตุจริงของโปเกม่อน** กับ **การวิวัฒนาการระหว่างเล่น** —
โปเกม่อนที่วางไว้จะเก็บ EXP จากการทำดาเมจ พอถึงเลเวลก็จ่ายเงินให้มันร่างใหม่ได้

![](docs/screenshot.png)

## เล่นยังไง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย (ดับเบิลคลิกก็ได้ ไม่ต้องมีเซิร์ฟเวอร์)

หรือถ้าอยากเสิร์ฟผ่าน http:

```bash
npx serve .          # แล้วเปิด http://localhost:3000
```

### ปุ่มลัด

| `1`–`0` | เลือกโปเกม่อนจากร้าน |

## ระบบหลัก

**ธาตุ** — ดาเมจคิดจากตารางธาตุจริงทั้ง 18 ธาตุ ศัตรูสองธาตุจะคูณตัวคูณซ้อนกัน
(ไฟ ใส่ แมลง/หญ้า = 4 เท่า) คู่ที่ปกติ "ไม่ได้ผลเลย" ถูกยกพื้นเป็น 0.25 เท่า
เพื่อไม่ให้ป้อมที่ลงทุนไปแล้วกลายเป็นขยะ

**วิวัฒนาการ** — แต่ละสายมี 2–3 ร่าง ต้องถึงเลเวลที่กำหนด *และ* มีเงินพอ
ร่างใหม่มักได้รูปแบบการโจมตีใหม่ด้วย เช่น Charmeleon ยิงเดี่ยว → Charizard ระเบิดเป็นวง

**ทีมจำกัด 12 ตัว** (ซื้อขยายได้ถึง 18) — บังคับให้ต้องเลือกว่าจะกระจายป้อมถูก ๆ
หรือทุ่มให้ไม่กี่ตัวจนสุดสาย และทำให้ EXP ไม่ถูกเฉลี่ยจนไม่มีใครโตทัน

**เกราะ** ลดดาเมจแบบสัดส่วน `dmg × 60/(60+armor)` ไม่ใช่ลบตรง ๆ
ป้อมยิงถี่จึงยังมีที่ยืน ส่วนสาย Ghost ทะลุเกราะได้หมด

**สถานะผิดปกติ** — ไหม้ / พิษ (ดาเมจต่อเนื่อง ไม่สนเกราะ), ช้าลง (ซ้อนกันได้ ใช้ค่าแรงสุด), หยุดชะงัก

**บอส** มี 8 ตัวทุก ๆ 5 เวฟ บางตัวมีออร่ากวน — Articuno ทำให้ป้อมรอบตัวยิงช้าลง,
Mewtwo ลดพลังโจมตี เลยวางป้อมกระจุกที่เดียวไม่ได้

## โครงสร้างไฟล์

```
index.html         หน้าเกม โหลดสคริปต์ตามลำดับ (ไม่ใช้ ES module จะได้เปิดจาก file:// ได้)
css/style.css
js/types.js        ตารางธาตุ 18x18 + สีประจำธาตุ
js/sprites.js      เครื่องวาดตัวละครแบบพารามิเตอร์ (ลำตัว/หู/หาง/ปีก/ตา/ปาก ประกอบกัน)
js/pokedex.js      ข้อมูลโปเกม่อนทั้งหมด — แก้ค่าพลังกับหน้าตาที่นี่ที่เดียว
js/map.js          ตารางช่อง เส้นทางเดิน และการวาดฉาก
js/waves.js        ตารางเวฟ 30 เวฟ
js/audio.js        เสียงสังเคราะห์ด้วย WebAudio (ไม่มีไฟล์เสียง)
js/entities.js     คลาสศัตรู / ป้อม / กระสุน / เอฟเฟกต์
js/game.js         สถานะเกม ลูปหลัก การคิดดาเมจ อินพุต
js/ui.js           ร้านค้า แผงข้อมูล HUD จอจบเกม
tools/             สคริปต์ทดสอบและปรับบาลานซ์ (ไม่เกี่ยวกับตัวเกม)
```

### เรื่องภาพ

ตัวละครทุกตัว **วาดขึ้นใหม่ด้วยโค้ดบน Canvas** ไม่ได้ใช้สไปรท์ต้นฉบับของ Nintendo
`js/sprites.js` ประกอบร่างจากชิ้นส่วน (`body`, `ears`, `tail`, `back`, `eyes`, `mouth`, `extra`)
บวกจานสี 4 สี เพิ่มตัวใหม่จึงเป็นแค่การเพิ่มอ็อบเจ็กต์หนึ่งก้อนใน `pokedex.js` ไม่ต้องวาดรูป

เปิด `tools/gallery.html` เพื่อดูตัวละครทั้งหมดเรียงเป็นตาราง — สะดวกตอนปรับหน้าตา

## เครื่องมือสำหรับปรับบาลานซ์

`tools/balance.js` เล่นเกมจนจบแบบไม่ต้องวาดภาพ โดยจำลอง AI ที่ซื้อ/วิวัฒนาการ/ป้อนลูกอมตามกลยุทธ์
แล้วรายงานว่าไปถึงเวฟไหน ทีมโตแค่ไหน DPS รวมเท่าไหร่ ใช้เช็คว่าแก้ค่าแล้วเกมยังเล่นได้จริงไหม

```bash
npm install playwright          # ครั้งเดียว
node tools/balance.js balanced  # หรือ mixed / cheap
node tools/smoke.js             # เปิดเกมจริง จับ error + เก็บภาพหน้าจอ
```

ค่าปัจจุบัน AI ทั้งสามแบบชนะแบบเหลือหัวใจ 2–5 จาก 25 — คือรอดแบบหวุดหวิด
ถ้าแก้ค่าพลังแล้วตัวเลขนี้เพี้ยนไปมาก แปลว่าบาลานซ์หลุด

## อยากแก้อะไรต่อ

- **เพิ่มโปเกม่อน** — เพิ่มใน `TOWERS` หรือ `ENEMIES` ใน `js/pokedex.js` ถ้าเป็นป้อมอย่าลืมใส่ id ลง `SHOP_ORDER`
- **เพิ่มด่าน** — `WAYPOINTS_T` ใน `js/map.js` คือจุดหักเลี้ยว แก้แล้วเส้นทางกับช่องห้ามวางอัปเดตเอง
- **เพิ่มเวฟ** — ต่อท้าย `WAVES` ใน `js/waves.js` ได้เลย จำนวนเวฟทั้งหมดคำนวณอัตโนมัติ
- **รูปแบบการโจมตีใหม่** — เพิ่ม case ใน `Tower.fire()` (`js/entities.js`) ตอนนี้มี bolt / splash / chain / beam / melee / aura
