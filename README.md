# Poke Defense

เกม tower defense แนวโปเกม่อน เล่นบนเบราว์เซอร์ล้วน ๆ ไม่ต้องติดตั้งหรือ build อะไรเลย

มี **โปเกม่อน Gen 1 ครบทั้ง 151 ตัว** ใช้สไปรท์จริงแบบเคลื่อนไหวชุด Black/White
และที่สำคัญกว่านั้นคือ **ค่าพลังทุกอย่างคำนวณจากสเตตัสจริง** ไม่ได้ตั้งมือ —
Atk/SpA สูงก็แรง, Spe สูงก็ยิงถี่, SpA มากกว่า Atk ก็เป็นสายยิงไกล, Def สูงก็มีเกราะหนา
บวกกับ **ระบบธาตุจริงครบ 18 ธาตุ** และ **การวิวัฒนาการระหว่างเล่น**

![](docs/screenshot.png)

## เล่นยังไง

แนะนำให้เสิร์ฟผ่าน http เพื่อให้สไปรท์ **เคลื่อนไหว** ได้:

```bash
npx serve .          # แล้วเปิด http://localhost:3000
```

เปิด `index.html` ตรง ๆ ด้วยการดับเบิลคลิกก็เล่นได้ แต่หน้า `file://` จะเรียก `fetch` ไม่ได้
ตัวเกมจะถอยไปใช้สไปรท์ภาพนิ่งแทน (ยังเป็นรูปจริงเหมือนเดิม แค่ไม่ขยับ)

| `S` | ขายตัวที่เลือก |

## ระบบหลัก

**ค่าพลังมาจากสเตตัสจริง** — นี่คือหัวใจของงานนี้ ไม่มีการตั้งค่าพลังมือทีละตัว
(151 ตัวทำไม่ไหวและจะไม่มีวันสมดุล) ทุกอย่างคำนวณจากสเตตัสจริงใน `js/derive.js`:

| สเตตัสจริง | กลายเป็นอะไรในเกม |
|---|---|
| max(Atk, SpA) | พลังโจมตี |
| Spe | ความเร็วในการยิง |
| SpA / (Atk+SpA) | ระยะโจมตี — ยิ่งเอนไปทาง SpA ยิ่งยิงไกล, Atk นำ = สายประชิดตีรัว |
| BST | ราคา (โตแบบกำลังสอง ตัวเทพจึงแพงกว่ามาก) |
| HP, Def, SpD | ความอึดตอนเป็นศัตรู |
| Def | เกราะ (ลดดาเมจแบบสัดส่วน) |
| ธาตุหลัก | รูปแบบการโจมตีและสถานะผิดปกติ |

ผลคือ Alakazam ยิงไกลมากแต่บาง, Machamp ต้องยืนติดทางแต่ DPS โหด, Onix เกราะหนาจนป้อมเบา ๆ เจาะไม่เข้า
— ตรงกับที่ควรจะเป็นโดยไม่ต้องจูนทีละตัว

**ธาตุ** — ดาเมจคิดจากตารางธาตุจริงทั้ง 18 ธาตุ ศัตรูสองธาตุจะคูณตัวคูณซ้อนกัน
(ไฟ ใส่ แมลง/หญ้า = 4 เท่า) คู่ที่ปกติ "ไม่ได้ผลเลย" ถูกยกพื้นเป็น 0.25 เท่า
เพื่อไม่ให้ป้อมที่ลงทุนไปแล้วกลายเป็นขยะ

**วิวัฒนาการ** — ร้านขายเฉพาะ **ร่างเริ่มต้นของสาย 79 ตัว** อีก 72 ตัวที่เหลือต้องวิวัฒนาการเอาเท่านั้น
เลเวลที่ต้องใช้อิงจากเลเวลจริงในเกมต้นฉบับ (เช่น Charmander วิวัฒน์ที่ 16 → ในเกมนี้ต้องถึง Lv.4,
Dragonair วิวัฒน์ที่ 55 → ต้องถึง Lv.13) ส่วนตัวที่ใช้หินหรือการแลกเปลี่ยนมีเงื่อนไขของตัวเอง
Eevee แตกสายได้ 3 ทางให้เลือกเอง

**ทีมจำกัด 12 ตัว** (ซื้อขยายได้ถึง 18) — บังคับให้ต้องเลือกว่าจะกระจายป้อมถูก ๆ
หรือทุ่มให้ไม่กี่ตัวจนสุดสาย และทำให้ EXP ไม่ถูกเฉลี่ยจนไม่มีใครโตทัน

**เกราะ** ลดดาเมจแบบสัดส่วน `dmg × 60/(60+armor)` ไม่ใช่ลบตรง ๆ
ป้อมยิงถี่จึงยังมีที่ยืน ส่วนสาย Ghost ทะลุเกราะได้หมด

**สถานะผิดปกติ** — ไหม้ / พิษ (ดาเมจต่อเนื่อง ไม่สนเกราะ), ช้าลง (ซ้อนกันได้ ใช้ค่าแรงสุด), หยุดชะงัก

**บอส** มาทุก 5 เวฟ: Onix → Gyarados → Articuno → Snorlax → Moltres (+Zapdos) → Mewtwo (+Dragonite +Mew)
บอสเดินช้ากว่าปกติแต่อึดมาก และบางตัวมีออร่ากวน — Articuno ทำให้ป้อมรอบตัวยิงช้าลง,
Dragonite/Mewtwo ลดพลังโจมตี เลยวางป้อมกระจุกที่เดียวไม่ได้

## โครงสร้างไฟล์

```
index.html         หน้าเกม โหลดสคริปต์ตามลำดับ (ไม่ใช้ ES module จะได้เปิดจาก file:// ได้)
css/style.css
js/types.js        ตารางธาตุ 18x18 + สีประจำธาตุ
js/gen1.js         ข้อมูล Gen 1 ครบ 151 ตัว — สร้างอัตโนมัติ ห้ามแก้มือ
js/derive.js       แปลงสเตตัสจริง -> ค่าพลังในเกม (ค่าจูนสมดุลอยู่ในบล็อก TUNE)
js/sprites.js      โหลดและวาดสไปรท์จริง ถอดเฟรม GIF เองด้วย ImageDecoder
js/map.js          ตารางช่อง เส้นทางเดิน และการวาดฉาก
js/waves.js        สร้างเวฟ 30 เวฟจากโปเกม่อนจริง แบ่งระดับตาม BST
js/audio.js        เสียงสังเคราะห์ด้วย WebAudio (ไม่มีไฟล์เสียง)
js/entities.js     คลาสศัตรู / ป้อม / กระสุน / เอฟเฟกต์
js/game.js         สถานะเกม ลูปหลัก การคิดดาเมจ อินพุต
js/ui.js           ร้านค้า แผงข้อมูล HUD จอจบเกม
tools/             สคริปต์สร้างข้อมูล ทดสอบ และปรับบาลานซ์ (ไม่เกี่ยวกับตัวเกม)
```

### เรื่องภาพ

ใช้สไปรท์จริงชุด **Black/White แบบเคลื่อนไหว** จากคลัง
[PokeAPI/sprites](https://github.com/PokeAPI/sprites)

**รูปไม่ได้ถูกเก็บไว้ในรีโปนี้** — ตัวเกมโหลดสดจาก CDN ตอนเล่น เฉพาะตัวที่โผล่บนจอจริง ๆ
รีโปจึงเบาและไม่ได้แจกจ่ายไฟล์ภาพของใคร

เบราว์เซอร์ส่วนใหญ่ไม่เดินเฟรม GIF ให้ตอนวาดลง `<canvas>` (จะได้แค่เฟรมแรกค้าง)
`js/sprites.js` เลยถอดเฟรมเองด้วย `ImageDecoder` (WebCodecs) แล้วคุมเวลาเอง
ถ้าเบราว์เซอร์ไม่รองรับก็ถอยไปใช้ PNG ภาพนิ่ง และถ้ายังโหลดไม่เสร็จก็วาดลูกบอลสีธาตุคั่นไว้ก่อน

**เล่นออฟไลน์** — โหลดรูปมาไว้เองแล้วชี้ไปที่โฟลเดอร์นั้น:

```html
<script>window.PTD_SPRITE_BASE = './sprites';</script>   <!-- วางก่อน js/sprites.js -->
```

โครงสร้างที่ต้องมีคือ `<base>/<id>.png` และ
`<base>/versions/generation-v/black-white/animated/<id>.gif`

เปิด `tools/gallery.html` เพื่อดูทั้ง 151 ตัวพร้อมราคาและ DPS ที่คำนวณได้ —
สะดวกมากตอนจูนค่าใน `TUNE`

## เครื่องมือ

```bash
npm install playwright                    # ครั้งเดียว

node tools/gen-pokedex.js <โฟลเดอร์ csv>   # สร้าง js/gen1.js ใหม่จากข้อมูล PokeAPI
node tools/balance.js starters            # จำลองเล่นจนจบ ดูว่าบาลานซ์โอเคไหม
node tools/smoke.js                       # เปิดเกมจริง จับ error + เก็บภาพหน้าจอ
node tools/waves-table.js                 # พิมพ์องค์ประกอบเวฟทั้ง 30 เวฟ
```

`tools/balance.js` คือตัวที่ใช้จูนสมดุลจริง — มันเดินลูปเกมเองโดยไม่วาดภาพ
พร้อม AI ที่ซื้อ/วิวัฒนาการ/ป้อนลูกอมตามกลยุทธ์ที่กำหนด แล้วรายงานว่าไปถึงเวฟไหน
DPS รวมเท่าไหร่ และ **ตัวไหนหลุดเข้าฐานบ้าง** (อันหลังนี่มีประโยชน์ที่สุดตอนหาว่าอะไรพัง)

ผลที่ควรได้ด้วยค่าปัจจุบัน:

| กลยุทธ์ | ผล |
|---|---|
| `starters` (สตาร์ทเตอร์ + ตัวคลาสสิก) | ชนะ เหลือ ~15/25 หัวใจ |
| `mixed` (คละธาตุ) | ชนะ เหลือ ~9/25 หัวใจ |
| `meta` (เลือกตาม DPS ต่อราคาอย่างเดียว) | แพ้ที่เวฟ 30 — คุ้มค่าแต่ธาตุไม่ครอบคลุม |
| `cheap` (ซื้อตัวถูกสุด) | แพ้ที่เวฟ 10 — ทีม Caterpie/Magikarp ไปไม่รอด |

ถ้าแก้ค่าใน `TUNE` แล้วตารางนี้เพี้ยนไปมาก แปลว่าบาลานซ์หลุด

## อยากแก้อะไรต่อ

- **ปรับสมดุล** — แก้ค่าในบล็อก `TUNE` ที่หัวไฟล์ `js/derive.js` แล้วรัน `tools/balance.js` ดูผล
- **เปลี่ยนบุคลิกของธาตุ** — ตาราง `STYLE` ใน `js/derive.js` กำหนดว่าแต่ละธาตุโจมตีแบบไหนและติดสถานะอะไร
  แก้ที่เดียวมีผลกับทุกตัวที่เป็นธาตุนั้น
- **เพิ่ม Gen 2+** — `tools/gen-pokedex.js` กรอง `generation_id === '1'` อยู่ เอาเงื่อนไขออกก็ได้ครบทุกเจน
  (สไปรท์เคลื่อนไหวชุด BW มีถึง id 649)
- **เพิ่มด่าน** — `WAYPOINTS_T` ใน `js/map.js` คือจุดหักเลี้ยว แก้แล้วเส้นทางกับช่องห้ามวางอัปเดตเอง
- **แก้บอส/เวฟ** — ตาราง `BOSSES` กับ `ESCORT` ใน `js/waves.js` ส่วนที่เหลือสร้างอัตโนมัติจาก BST
- **รูปแบบการโจมตีใหม่** — เพิ่ม case ใน `Tower.fire()` (`js/entities.js`) ตอนนี้มี bolt / splash / chain / beam / melee / aura
