วิธีเล่น

  1. เลือกโปเกม่อนจากแถบขวา แล้วคลิกบนพื้นหญ้าเพื่อวาง (วางบนทางเดินหรือบนต้นไม้/หินไม่ได้)
  2. ร้านมีเฉพาะ ร่างเริ่มต้น ของแต่ละสาย 79 ตัว — ร่างหลังจากนั้นต้องวิวัฒนาการเอาเท่านั้น ใช้ช่องค้นหาหรือกรองธาตุเพื่อหาตัวที่ต้องการ
  3. ศัตรูจะเดินจากป้าย เข้า ไป ออก ถ้าหลุดออกไปได้จะเสียหัวใจ หมดหัวใจคือแพ้
  4. โปเกม่อนได้ EXP จากการทำดาเมจ พอถึงเลเวลที่กำหนดจะมีลูกศร ▲ ขึ้นเหนือหัว = วิวัฒนาการได้
  5. วิวัฒนาการต้องจ่ายเงิน แต่คุ้มมาก — พลังกระโดดเป็นเท่าตัวและมักได้ท่าใหม่
  6. กดเรียกเวฟก่อนหมดเวลาพัก จะได้เงินโบนัสตามวินาทีที่เหลือ

ระบบธาตุคือหัวใจ

ความเสียหายคิดจากตารางธาตุจริงของโปเกม่อน — ท่าธาตุไฟใส่ธาตุหญ้าได้ 2 เท่า, ใส่ธาตุน้ำเหลือครึ่งเดียว และถ้าศัตรูมีสองธาตุ ตัวคูณจะคูณกัน (เช่น ไฟ ใส่ แมลง/หญ้า = 4 เท่า)

หมายเหตุ: ในเกมจริงบางคู่ธาตุจะ “ไม่ได้ผลเลย” (0 เท่า) แต่ในเกมนี้ปรับพื้นเป็น 0.25 เท่า เพื่อไม่ให้ป้อมกลายเป็นไร้ประโยชน์สนิท

สถานะผิดปกติ

  • ไหม้ / พิษ — เสียเลือดต่อเนื่อง ไม่สนใจเกราะ
  • ช้าลง — ลดความเร็วเดิน ซ้อนกันได้แต่ใช้ค่าที่แรงที่สุด
  • หยุดชะงัก — หยุดนิ่งชั่วครู่

ค่าพลังมาจากไหน

ทุกตัวใช้ สเตตัสจริงของโปเกม่อน คำนวณเป็นค่าในเกม ไม่ได้ตั้งมือ:

  • Atk / SpA ที่สูงกว่า → พลังโจมตี
  • Spe → ความเร็วในการยิง
  • ตัวที่ SpA มากกว่า Atk → สายยิงไกล, ตัวที่ Atk นำ → สายประชิดตีรัว
  • Def / SpD / HP → ความอึดและเกราะตอนเป็นศัตรู
  • BST (ผลรวมสเตตัส) → ราคา

เลเวลที่ต้องใช้วิวัฒนาการก็อิงของจริง — ตัวที่เกมต้นฉบับวิวัฒน์ที่เลเวลสูง ในเกมนี้ก็ต้องเลี้ยงนานกว่า ส่วนตัวที่ใช้หินหรือการแลกเปลี่ยนจะมีเงื่อนไขของตัวเอง

ทิป

  • ศัตรูที่ Def สูง (Onix, Golem, Cloyster) มีเกราะหนา ลดดาเมจเป็นสัดส่วน — สาย Ghost อย่าง Gastly ทะลุเกราะได้หมด
  • บอสบางตัวมีออร่ากวน — Zapdos ทำให้ป้อมรอบตัวยิงช้าลง, Dragonite/Mewtwo ลดพลังโจมตี อย่าวางป้อมกระจุกที่เดียว
  • สายหญ้ากับน้ำแข็งหน่วงศัตรูได้ดี วางไว้ต้นทางแล้วให้ตัวดาเมจสูงรุมตรงโค้ง
  • Eevee วิวัฒนาการได้ 3 ทาง (Vaporeon / Jolteon / Flareon) เลือกให้ตรงกับธาตุที่เวฟหน้าต้องการ
